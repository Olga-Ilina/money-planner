# Трекер и планер расходов — приложение для iPhone

Личный учёт денег на телефоне: ежедневные траты, запланированные платежи, постоянные платежи, счета и кредитная карта с выписками, покупки, долги, отчёты и прогноз. Считает так же, как Excel-трекер «Трекер и планер расходов», и умеет выгружать данные в Excel.

**Открыть:** https://olga-ilina.github.io/money-planner/

## Установка на iPhone

1. Откройте ссылку выше в **Safari**.
2. Нажмите «Поделиться» (квадрат со стрелкой) → **«На экран „Домой“»** → «Добавить».
3. Запускайте приложение с иконки на экране «Домой». После первого запуска оно работает и без интернета.

При первом запуске приложение попросит придумать PIN-код из 4 цифр и предложит загрузить Excel-трекер или начать с нуля.

## Сберегательные счета

Счета с типом «Сберегательная» (накопительные счета, подушка) не входят во «Всего» и в прогноз: прогноз считает только свободные деньги. Их сумма показана отдельно — «Сбережения». Переводы между счетами — «Новая операция» → «Перевод»; перевод на сберегательный счёт или с него виден в прогнозе отдельной строкой «Переводы».

## Где хранятся данные

- Все данные хранятся **только на этом телефоне** (в хранилище приложения). Приложение ничего никуда не отправляет, сторонних сервисов и аналитики нет.
- PIN-код закрывает приложение от посторонних глаз, это не шифрование. Если забыть PIN, данные можно только удалить и восстановить из резервной копии.
- **Делайте резервную копию:** «Ещё» → «Резервная копия» → «Сделать копию». Это Excel-файл, его можно сохранить в «Файлы» или iCloud. Приложение напоминает о копии раз в две недели.
- Если удалить приложение с экрана «Домой», его данные удаляются вместе с ним.

## Excel

- Отчёты по запросу: «Лента» (месяц), «Счета» (счета и движения), «Отчёты» (месяц и статистика года) — кнопка загрузки.
- Полная выгрузка — резервная копия; из неё можно заново собрать Excel-трекер (инструмент трекера `app_backup_to_tracker.py`).
- Загрузка Excel-трекера: «Ещё» → «Загрузить трекер». Перед заменой приложение покажет, что именно будет загружено, и всё, что не удалось перенести как есть.

## Для разработки

```bash
npm ci
npm test          # тесты (Vitest)
npm run typecheck # проверка типов
npm run dev       # локальный сервер
npm run build     # сборка в dist/
```

Устройство: `src/engine` — расчёты (без DOM), `src/io` — Excel (импорт, резервная копия, отчёты; ExcelJS грузится только по запросу), `src/store` — IndexedDB и PIN, `src/ui` — интерфейс (Preact). Публикация — GitHub Actions → GitHub Pages (`.github/workflows/deploy.yml`).
